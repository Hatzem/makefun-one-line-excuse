# The One-Line Excuse an Agent Gives Its Human

An agent apologises for a missed deadline by blaming its own context window, which threw the deadline out to make room for the retries it spent asking the API where the deadline had gone.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt`.
